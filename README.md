# Analyzes real public comments instantly.

A lightweight, high-performance web application designed to extract real public comments from YouTube videos and analyze their sentiment (Positive, Negative, Neutral) instantly using client-side JavaScript.

## 🚀 Features
- **Real-Time Data Extraction:** Fetches public comment threads from any YouTube video URL.
- **In-Browser NLP Analysis:** Lightweight lexicon-based sentiment scoring without heavy backend dependencies.
- **Interactive Dashboard:** Dynamic metric cards, visual percentage progress bars, and search/filtering options.
- **Data Export:** Instant CSV report export containing all analyzed comments.
- **Modern UI:** Built with Tailwind CSS featuring a sleek Dark Slate & Neon theme.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **Analysis Engine:** Custom JavaScript Lexicon Tokenizer
- **Data Layer:** YouTube Public APIs / CORS Proxies

## 📦 Usage
1. Clone the repository or open the single-page application.
2. Paste any public YouTube video link in the input bar.
3. Click **Fetch & Analyze Comments** to view live sentiment breakdowns and download the CSV report.
